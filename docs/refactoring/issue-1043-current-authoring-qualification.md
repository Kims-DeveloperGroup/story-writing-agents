# 현재 작성 권한·편집 자료·입력 자격 분리

상세 범위·API·기존 테스트 이동표·검증 기준은
[이슈 #1043의 구현 계획](https://github.com/Kims-DeveloperGroup/story-writing-agents/issues/1043#구현-계획)에서 관리한다.
상위 범위는 [#968](https://github.com/Kims-DeveloperGroup/story-writing-agents/issues/968)이며,
현재 고정 잔여 7개·전체 자식 18개의 범위를 유지한다.

이 문서는 구현 전 Draft PR을 연결하는 문서 변경이다.
Runtime·테스트 구현과 실행 검증은 아직 수행하지 않았다.

기준 main은 `d66b50e93f3a5a09748fb9a90feecf326124333e`,
전체 tree는 `82bf1d1e08889f0ec78fd5d716cfb8ceb06443f8`이다.
기존 정상 실행 3회의 같은 전체 tree를 변경 전 시간 기준으로 사용한다.
