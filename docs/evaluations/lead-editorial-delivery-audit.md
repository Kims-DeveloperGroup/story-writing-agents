## Safeguards reconciled on the accepted base

Exact sources, the originating task, assignment responsibility, complete draft
integration, and the immutable final candidate remain bound through review.
The offline tool imports no runtime modules and grants no runtime authority.
Stored comparative output is observational data, not a workflow candidate,
approval, READ receipt, Apply result, or Commit request.

The retained provider-free guards include:

- `tests.test_runtime_reference_integration.RuntimeExecutionRetirementTests.test_management_construction_and_inspection_do_not_bind_or_call_provider`
- `tests.test_lead_artifact_objectives.LeadArtifactObjectiveTests.test_only_matching_successful_apply_satisfies_objective`
- `tests.test_specialist_routing_runtime.SpecialistRoutingRuntimeTests.test_draft_integrates_exact_all_role_review_apply_and_storage_parity`
- `tests.test_consensus_story_runtime_bridge.ConsensusStoryRuntimeBridgeTests.test_prompt_and_supplied_draft_are_execution_authored_before_audit`

Matching successful Apply satisfies an artifact objective; a review, prose
approval, exploration/adoption, comparative report, or Git Commit does not.
Required specialist domains and separate Confirm, Apply, and Commit boundaries
remain authoritative. Editorial memory cannot replace source-reading evidence
and an optional missing citation does not invent a provider's approval.

The final #800 evidence identifies the exact committed candidate, frozen source,
selected IDs, complete canonical CI, source/subtest/inventory budgets, authentic
review closure, and integration state. Its tests also exercise successful offline
reproduction, stale hidden-metadata bindings, strict current inputs, readable
separate scores, missing evidence, and output-directory/input preservation.
